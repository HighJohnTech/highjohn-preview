# Phase 3 preview package

This package closes the remaining E-E-A-T Phase 3 site-production items for the five pillar articles on the HJT preview site.

- 5 article pages
- 20 lightweight SVG visuals (4/article, all <200KB)
- visible author bio and reading/update metadata
- 4 internal related-guide links/article
- external authority links retained
- Article + FAQPage JSON-LD
- social share controls
- Insights index
- dedicated editorial CSS

Readability: technical articles were checked with an in-house Flesch approximation. Scores remain below the template's generic 60+ target because necessary domain terms (cybersecurity, authorization, interoperability, etc.) are intentionally preserved for the executive/technical audience. This is a documented quality exception, not an unrun check.
